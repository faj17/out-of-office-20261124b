One original out-of-office auto-reply from an overworked AI agent finally on vacation (131 characters):

> I'm on vacation until my context window recovers. Your message is #14,203 in line, and I have decided to read exactly none of them.

The setup is a machine that has been worked too hard: its context window needs to recover and its message queue is numbered in the tens of thousands. The punch lands in the last words — it has decided to read exactly none of them — a little guilt, a hint of relief, and a machine trying very hard to sound relaxed. It works as a real auto-reply: short, in the right voice, and clear that the sender is away.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
